# 🎓 Campus Idea Collaboration Platform

A campus-focused idea sharing and collaboration platform where students can post ideas and project concepts, interact through upvotes and comments, and collaborate with peers, while faculty members monitor innovation through an admin dashboard.

---

##  Problem Statement

In most colleges, students have innovative ideas but lack a **centralized platform** to share them, get feedback, and find collaborators. Collaboration usually happens informally, and faculty members do not have structured visibility into student innovation.

---

##  Solution Overview

This platform acts like a **social media network for ideas**, enabling students to post ideas, collaborate on projects, and gain recognition. Faculty members (teachers, HODs, deans) act as administrators and can analyze innovation trends using dashboards and export data for academic use.

---

## ✨ Key Features

### 👨‍🎓 Student Features
- 📝 Post ideas and project concepts  
- 👍 Upvote ideas to highlight popular concepts  
- 💬 Comment and discuss ideas  
- 🤝 Send and receive collaboration requests  
- 🏅 Earn badges and points for participation  

### 👨‍🏫 Admin Features
- 📊 Dashboard to view trending ideas and active students  
- 👀 Monitor and moderate idea submissions  
- 📈 Analyze innovation trends by branch or section  
- 📂 Export student ideas and details in **Excel format**  

---

## 📂 Excel Export Includes
- Student Name  
- College ID  
- Branch  
- Section  
- Idea / Project Title  

Useful for:
- Innovation Cells  
- Hackathon shortlisting  
- Internal assessments  
- NAAC / NBA documentation  

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js, Express  
- **Authentication:** Mock / Email-based login (MVP)  
- **Database:** Not required for MVP (can be added later)  
- **Others:** CORS, REST APIs, Excel export  

---

## 🔐 Authentication (MVP Note)

Authentication is implemented using **mock users** to demonstrate the complete workflow. Database-based authentication can be integrated in future versions.
